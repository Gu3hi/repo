LOCK SCREEN, REIMAGINED

Quart17

2.7.103Put_Story

Quart17 为越狱设备提供可定制的锁屏音乐播放器、专辑封面、通知排版与缩放，以及下拉清理手势。

Quart17 brings a customizable Lock Screen music player, album artwork, notification layouts and scaling, and pull-to-clear gestures to jailbroken devices.

功能 / Features

锁屏音乐播放器

Lock Screen player

播放控制、封面位置与缩放，支持封面进度交互。

Playback controls, artwork positioning and scaling, with artwork-based seeking.

通知排版与缩放

Notification layout

调整通知卡片尺寸，让锁屏列表更清晰。

Adjust notification card sizes for a cleaner Lock Screen list.

下拉清理手势

Pull to clear

通过手势清理通知，并在设置中调整选项。

Clear notifications with a gesture and customize behavior in Settings.

配合 Aura

Works with Aura

当前拆分版的玻璃效果由 Aura 提供；Quart17 保留播放器与通知功能。

Aura provides glass rendering in the current split edition; Quart17 handles player and notification features.

安装说明 / Installation

面向 iOS 16–17 越狱环境；2.7.103 包含 iOS 16 播放器识别兼容调整。Rootless 与 RootHide 安装包不可混用。安装后进入「设置 → Quart17」配置。

For jailbroken iOS 16–17 devices. Version 2.7.103 includes an iOS 16 player-detection compatibility adjustment. Use the package matching Rootless or RootHide, then configure Settings → Quart17.
