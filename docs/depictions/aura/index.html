功能 / Features安装 / Installation更新记录 / Changelog
01FEATURES · 功能
01

通知与锁屏Notifications & Lock Screen

通知卡片、横幅与锁屏通知玻璃，可调圆角、底色和边缘高光；支持 Quart17 播放器玻璃。

Glass for notification cards, banners, Lock Screen notifications and the Quart17 player, with adjustable corners, tint and edge highlights.

02

控制中心与桌面Control Center & Home Screen

控制中心模块、Dock、文件夹、桌面搜索胶囊、App 资源库搜索框与音量条玻璃。

Glass for Control Center modules, the Dock, folders, Home Screen search, App Library search and the volume HUD.

03

弹窗与菜单Popups & menus

系统弹窗、快捷菜单与弹出按钮玻璃，支持通知与弹窗强制深色。

Glass for system popups, context menus and pop-up buttons, with forced dark appearance options for notifications and popups.

04

按 App 配置组件Per-app components

独立开关 Tab 栏、标准按钮、搜索框玻璃与导航栏渐进模糊，也可去除分割线。

Per-app controls for tab bar, standard button and search bar glass, progressive navigation bar blur and separator removal.

05

高光与动态效果Highlights & motion

陀螺仪高光随手机倾斜改变光源方向；锁屏上滑边缘圆角与折射属于实验功能。

Gyroscope-driven highlights respond to device tilt. Lock Screen swipe-up edge rounding and refraction are experimental.

06

预设与偏好备份Presets & preference backup

支持应用作者预设、复制与导入偏好。使用设备绑定激活码，激活后可离线使用。

Apply the author preset and copy or import preferences. Uses device-bound activation and works offline after activation.

安装与激活 Installation & activation

安装与越狱环境匹配的一个包：Rootless 为 iphoneos-arm64，RootHide 为 iphoneos-arm64e。安装后前往「设置 → Aura」配置。Aura 使用设备绑定激活；安装包下载不代表已激活。

Install one package matching your jailbreak: iphoneos-arm64 for Rootless, or iphoneos-arm64e for RootHide. Configure Settings → Aura after installation. Aura uses device-bound activation; downloading the package does not activate it.

当前上架 1.2.45 预发布版，真机验收尚未完成，Rootless 未实机测试。搜索和键盘玻璃目前未生效。

Version 1.2.45 is a prerelease; device validation is pending and Rootless has not been tested on a physical device. Spotlight and keyboard glass are currently ineffective.

4公开发布 / Public releases
1.2.452026-10-31＋

通知玻璃与 Quart17 播放器玻璃改用苹果连续圆角，圆角拉满时保持正圆与胶囊形。播放器圆角设置移至 Quart17（需配合 Quart17 2.8.2，原有数值自动沿用）。包含 1.2.41–1.2.44 的桌面液态玻璃、锁屏时钟与静音胶囊改进。仍为预发布版，RootHide 已在 iOS 17 真机安装运行，完整验收尚未完成，Rootless 未实机测试。

Notification glass and the Quart17 player glass use Apple continuous corners, keeping true circles and capsules at full roundness. The player corner setting moves to Quart17 (use with Quart17 2.8.2; the existing value carries over). Includes the 1.2.41–1.2.44 desktop liquid glass, Lock Screen clock and ringer pill improvements. Still a prerelease: RootHide is installed and running on an iOS 17 device, full validation is pending, and Rootless has not been tested on a physical device.

原始发布说明 / Release notes ↗

1.2.402026-10-27＋

新增 Tab 玻璃拖动与触摸反馈、深色适配；新增锁屏快捷按钮和桌面小文件夹玻璃效果；新增设置开关与滑块玻璃样式。

Adds glass dragging and touch feedback for tab bars with dark-mode adaptation, glass for Lock Screen shortcuts and small Home Screen folders, and glass-style settings switches and sliders.

原始发布说明 / Release notes ↗

1.2.232026-10-11＋

同版本修订：两个安装包已替换为弹窗入场时机修正版。桌面“移除 App／删除 App”等确认框在入场前准备玻璃，避免动画结束后才切换背景。改善相册标签与应用组件在布局变化、视图复用及关闭效果后的还原，减少标准按钮玻璃的重复查找与更新。发布包不包含 Tab 触摸诊断模块。已安装此前 1.2.23 的用户需重新下载并重新安装对应包。仍为预发布版，安装后真机验收尚未完成，Rootless 未实机测试。

Same-version revision: both packages were replaced with the corrected alert presentation build. Glass is prepared before Home Screen app removal confirmation dialogs enter, avoiding a background switch after the animation. Improves restoration of Photos labels and app components after layout changes, view reuse and disabling effects; reduces repeated searches and updates for standard button glass. Release packages exclude Tab touch diagnostics. Users of the earlier 1.2.23 build should download and reinstall the matching package. Still a prerelease: post-install device validation is pending, and Rootless has not been tested on a physical device.

原始发布说明 / Release notes ↗

1.2.112026-10-06＋

公开预发布记录介绍了通知与锁屏、Quart17 播放器、控制中心模块、弹窗与菜单、Dock、文件夹及搜索区域的玻璃效果；应用组件支持按 App 开关，包含 Tab 栏、标准按钮、搜索框与导航栏渐进模糊。另列出陀螺仪高光、实验性锁屏上滑边缘折射、作者预设、偏好复制与导入、设备绑定激活及激活后离线使用。提供 Rootless 与 RootHide 两种包，支持 iOS 16–17。该发布说明以功能清单为主，未逐项区分本版新增与既有功能。

The public prerelease documents glass for notifications, the Lock Screen, the Quart17 player, Control Center modules, popups, menus, the Dock, folders and search surfaces. Per-app component toggles cover tab bars, standard buttons, search bars and progressive navigation bar blur. It also lists gyroscope highlights, experimental Lock Screen swipe-up edge refraction, author presets, preference copy/import, and device-bound activation with offline use after activation. Rootless and RootHide packages support iOS 16–17. These release notes are primarily a feature list and do not distinguish each new feature from existing behavior.
